﻿========================================
  简递  ·  使用说明
========================================

【三个版本怎么选】

  安装包（最推荐）      双击安装，自动建桌面图标和开始菜单项
    投递工具\安装包\简递-Setup-1.0.0.exe
    安装到  C:////Users////<你的用户名>////AppData////Local////Programs////简递
    卸载：开始菜单 → 简递 → 卸载（不会删你的投递记录）

  桌面版（免安装）      不写注册表，解压即用，适合放 U 盘
    投递工具\桌面版\简递.exe

  命令行版             黑窗口菜单，适合挂计划任务、无人值守
    投递工具\命令行版\简递.exe

  三个版本功能一致，但数据各存各的（安装版与免安装版互不相通）。


【第一次使用】

  1. 装安装包的话：双击「投递工具\安装包\简递-Setup-1.0.0.exe」，
     一路下一步即可（可以改安装位置）。装完桌面和开始菜单都有图标。

     不想安装就用免安装版：双击「投递工具\桌面版\简递.exe」。

  2. 如果 Windows 弹出「已保护你的电脑」：
     点「更多信息」→「仍要运行」。
     程序没有数字签名，属于正常现象。

  3. 浏览器要求：Chrome 或 Edge 任选其一即可
     · 装了 Chrome 就自动用 Chrome；
     · 没装 Chrome 会自动改用 Windows 自带的 Edge，不用额外装东西；
     · 两个都没有时（极少数精简版系统）程序会提示你装一个；
     · 绿色版 / 便携版浏览器，可以把 exe 完整路径写进
       「简递数据\browser.txt」手动指定（只写一行路径）。
     · 浏览器只需要检测一次：第一次找到后程序会记住它，
       以后直接使用，不再重复扫描；万一你换了浏览器或删掉了它，
       删掉「简递数据\browser-cache.json」再启动就会重新检测。

  4. 程序会自动打开一个「专用浏览器窗口」（独立的配置目录，
     和你平时用的浏览器互不影响，所以你平时那个浏览器
     开着也没关系，不用先关掉）。

  5. 第一次用，请在这个专用窗口里登录一次 BOSS / 牛客 / 智联 / 猎聘
     （扫码或手机号都行）。登录状态会存在专用目录里，
     以后每次打开都还在，不用重复登录。

  6. 登录状态失效时程序会自动停下等待：
     不管是弹登录框、还是整页被跳到登录页，甚至出现滑块验证，
     程序都会一直等你处理完，处理好后自动继续，不用回来点按钮。
     如果你习惯新开一个标签页登录，程序也能识别到，会自动刷新同步并继续。
     最长等 10 分钟，超时会结束本轮并提示。


【怎么用】

  ① 选平台
     BOSS     —— 按城市搜岗位，逐个打招呼
     牛客     —— 实习岗一键投递
     智联     —— 实习优先，按城市搜岗位一键投递
     猎聘     —— 猎聘（liepin.com），中高端岗多，实习岗集中在大城市

  ② 选城市（四个平台都用）
     BOSS：按这个城市搜索岗位，必选。
     牛客：同样生效，会通过牛客的「全部城市」下拉框按地区筛选。
     智联：按智联自己的城市编码搜索，必选。
     猎聘：可选全国（默认，岗位最多）或任意城市（如南宁 / 桂林 / 深圳）。
           城市是猎聘自己的一套编码，程序内置了 400 个城市。
     在搜索框输入城市名，比如「佛山」「乌鲁木齐」「喀什」。
     全国 373 个城市都支持，输入省份名也能筛（比如输「广西」）。
     选中后会自动进入「常用城市」，下次直接点。
     鼠标停在常用城市上会出现红色 ×，点它可以移除。
     牛客不选城市 ＝ 全国不限地区。

  ③ BOSS 的求职类型（切到「BOSS」才会出现）
     不限 / 全职 / 兼职 / 实习，默认「实习」。
     与 BOSS 搜索页顶部「求职类型」下拉一一对应。程序会把这一项
     写进搜索地址（jobType=1902），浏览器顶部筛选条会显示成已选中，
     列表出来的就是实习岗，不是靠本地过滤凑数。
     实习岗在 BOSS 上按「150~200 元/天」标价，数量比社招少；
     想多攒数量就切「不限」，或把关键词换成「前端实习、开发实习生」。
     选「全职」时会自动把日薪的实习卡排除掉。

  ④ 填投递数量
     想投多少个就填多少，完全自定义。
     留空 ＝ 不限，一直投到平台当日额度用完为止。
     BOSS 每天最多沟通 150 位，牛客没有硬性上限。

  ⑤ 智联的其他筛选（切到「智联」才会出现）
     工作性质：不限 / 全职 / 兼职·临时 / 实习 / 校园，默认「实习」。
       这五项跟智联自己的「工作性质」下拉一一对应。
       程序是直接在智联页面上把这一项勾上的（URL 带 jobStatusCode），
       浏览器窗口顶部筛选条会显示成蓝色选中的「实习」，列表出来的
       也全是实习岗，不是靠本地过滤凑数。
     学历要求：不限 / 大专 / 本科。
       同样会在页面上勾上（educationTypeCode），「学历不限」的岗位保留。
     注：智联以社招为主，南宁这类城市实习技术岗很少。

  ⑥ 牛客的其他筛选（切到「牛客网」才会出现）
     岗位类型：实习 / 校招 / 全部。
     学历要求：不限 / 专科 / 本科 / 硕士，
       对应牛客「筛选」面板里的学历要求，选本科就只看要求本科的岗位。
     这些条件都会真的在牛客页面上勾选，不是本地猜的。

  ⑥-2 猎聘的筛选（切到「猎聘」才会出现）
     工作性质：不限 / 全职 / 兼职 / 实习，默认「实习」。
       猎聘搜索页没有可靠的「实习」筛选参数，程序按岗位标题和
       「经验/学历」标签再筛一层（标题或标签里带「实习/在校/应届」）。
     学历上限：不限 / 大专 / 本科，只投「要求不高于所选学历」的岗位，
       避免一堆要硕士的岗位占位。
     采集靠解析搜索结果页（猎聘接口有反爬签名，直接调会被 400 拒掉），
     一页 40 个、自动翻页，多个关键词累加去重。

  ⑦ 检索关键词
     四个平台共用同一份关键词，切平台（BOSS / 牛客 / 智联 / 猎聘）不用重填。
     只用空格分隔，程序会逐个关键词搜索（逗号不再当分隔符）。
     第一次打开是空的，必须自己填（不填不让开始），
     填过会自动记住，下次打开还在。建议写得准一点，
     比如「前端实习 软件开发 实施工程师」。

  ⑧ 点「开始投递」
     右侧实时滚动日志，能看到每一轮的采集和投递结果。
     顶部四个数字：成功 / 失败 / 跳过 / 扫描。
     中途想停，点左侧「停止」。

  ⑨ 看结果 / 接着投
     切到「历史任务」标签，每条任务都记着当时的平台、城市、
     关键词、筛选条件和已投/待投岗位。
     · 已停止的任务：点进去，右上角有「继续任务」
     · 已结束的任务：点进去看明细，右上角「投递报告」看原始报告

  快捷键：Ctrl + Enter 直接开始
  主题：右上角月亮 / 太阳图标，深色浅色随时切换（会记住）


【版本更新】

  程序会自动检查有没有新版本：
  · 每次启动 4 秒后查一次
  · 之后每 10 分钟查一次（所以就算一直开着，发了新版也会弹出来）
  · 也可以点左上角标题栏的版本号「v1.0.0」手动检查

  弹窗分两种：

  可选更新
    右下角两个按钮：「稍后再说」「立即更新」。
    可以点「跳过这个版本」，跳过之后这个版本不再打扰你，
    等下一个版本再提醒。

  强制更新
    只有「立即更新」一个按钮，关不掉窗口，也退不出程序。
    （这是发布方在更新清单里设的 force 或最低版本要求的，
     不是 bug。装完关闭安装向导后会自动重新打开。）

  点「立即更新」后：
    1. 自动下载安装包，弹窗里显示进度和速度
    2. 下载完自动校验文件（大小 + SHA256）
    3. 校验通过后自动启动安装向导，程序自己退出
    4. 安装向导一路下一步即可，装完会自动重新打开

  更新不会动你的数据：投递记录、配置、报告都在数据目录里，
  安装包里也不包含这些内容。


【投递逻辑说明】

  会自动跳过这三类，不浪费额度：

  · 岗位名不匹配方向的（销售、运营、客服、人事、财务、
    数据标注、众包出题、工厂普工…）
  · 要求硕士 / 博士，或 2028 届及以后的
  · 历史上已经投过的（程序记录在案，不会重复投）

  智联的投递是一键完成：点「立即投递」直接发出简历+打招呼语，
  不需要选简历。程序会先核对右侧详情面板的公司名是否一致，
  再点投递，避免点错卡片投错公司。

  · 智联的搜索结果每次刷新都会变，之前看到的岗位可能被新岗位挤到
    后面几页，按标题在列表里找不到。这时程序会改用「直达岗位页」
    的方式投递（每个岗位都有固定的详情页地址），只要岗位还没下架
    就能投出去，不会因为没有出现在第一页就白白跳过。

  牛客的岗位分两种弹窗：
  · 只有「投递简历」按钮       → 一键投递，成功
  · 多出「请选择志愿」下拉      → 属于专场招聘，只能走企业网申，
                               程序会自动识别并跳过

  猎聘的投递：进职位详情页点「申请职位」，如果弹出选简历/确认框，
  程序会自动点确认，再回读页面判断是否变成「已申请」。
  · 猎聘对未登录访客会把详情页整页跳到登录落地页（wow.liepin.com），
    这是正常的：程序会停下来等你登录，登录后自动回到该岗位继续投。
  · 只有「聊一聊」没有「申请职位」的岗位投不了，程序会跳过并在日志里
    写清实际按钮文案（方便判断是不是页面改版）。
  · 提示「请先完善在线简历」的岗位会被记为「需简历」并跳过。


【历史任务 / 中途停止怎么接着投】

  每点一次「开始投递」，都会生成一条任务记录，包含：
  · 当时的条件：平台、城市、关键词、工作性质、学历、目标数量
  · 采集到的岗位（最多存 800 条）
  · 已经投成功的、失败的、以及还没投的明细

  中途点「停止」后，这条任务会标成「已停止」存进「历史任务」。
  之后想接着投：
    1. 切到「历史任务」标签
    2. 点那条「已停止」的记录
    3. 详情页最上面绿色那条里点「继续任务」（就在标题下面，很显眼）

  继续时会做这些事：
  · 把上次的关键词 / 城市 / 筛选条件自动填回左侧（也写进日志）
  · 上次采集到的岗位直接沿用，不用重新搜一遍
  · 已经投过的按记录跳过，不会重复投
  · 目标数量按「剩下的」算：上次设 50 投了 12，这次再投 38 就够了

  也就是说，不用怕半途停止：停了不丢进度，随时能续上。

  只有「已停止 / 出错停了」的任务能继续；「已完成」的任务点进去只能看明细，
  不能再续投（想再投就回左侧点「开始投递」开新任务）。
  投递失败的岗位会标红列出来，方便你自己去补。

  续投会新开一条任务记录，老记录上标「已续投」，避免对同一条重复续投；
  如果续出来的新任务又中途停了，再去继续那条新的就行。

【跑完之后关掉浏览器】

  任务结束（投完 / 停止 / 中断）后，左侧「开始投递」下面会多出一个
  「关闭浏览器」按钮，点一下就把投递专用的那个浏览器窗口关掉。

  · 只关程序自己开的那个窗口（用的是「简递数据」旁边的专用配置目录），
    你平时自己用的浏览器不会被关掉，正在开的网页也不受影响。
  · 关掉不影响记录：下次点「开始投递」会自动重新打开，登录状态还在，
    不用重新扫码。
  · 任务还在跑的时候不会显示这个按钮；想关先点「停止」。

【数据存在哪】

  投递工具\桌面版\简递数据\
    config.json            你的配置（关键词、常用城市等）
    applied_history.json   已投递岗位记录（防重复投）
    投递报告_*.md          每次运行的报告
    tasks                 历史任务（条件 + 采集结果，用于继续投）
    update_state.json      更新检查状态（跳过了哪个版本）

  旧版本的 AutoApplyBot-data 目录会自动迁移过来，历史记录不丢。
  想清空重来，删掉这个文件夹即可（会丢失已投记录）。


【常见问题】

  Q: 提示「浏览器调试通道没有开起来」
  A: 1) 先把之前那个「专用浏览器窗口」全部关掉，再点开始
        （同一个配置目录只有第一次启动参数生效）；
     2) 360 / 火绒等安全软件可能拦调试端口，临时放行；
     3) 仍不行就按日志里给出的命令手动启动一次。

  Q: 浏览器窗口里显示未登录
  A: 在这个窗口里登录一次即可（程序会等你登录完自动继续）。
     如果你是在另一个标签页登录的，程序也会发现并自动同步，稍等 3~5 秒。
     登录状态记在 %LOCALAPPDATA%\AutoApplyBot\chrome-profile，
     删掉这个目录等于重置登录，需要重新登录一次。

  Q: 为什么打开的不是我平时那个浏览器
  A: Chrome / Edge 136 之后，用默认配置目录会拒绝开启调试接口
     （所以老版本才会一直弹「允许远程调试」并且连不上）。
     现在改用独立配置目录，窗口看起来是新装的 Chrome，
     登录一次之后就和你平时用的一样了。

  Q: 点版本号提示「暂未配置更新源」
  A: 说明发行方还没填更新地址，不影响使用。
     配置方法见「投递工具\发布工具\更新发布指南.md」。

  Q: 强制更新弹窗关不掉
  A: 这是发布方设置的强制更新，必须装完才能用。
     如果网络不好下载失败，点「重试」即可，不会卡死。

  Q: 投递全部失败，按钮还是「立即沟通」
  A: 多半是当日 BOSS 150 位额度用完了，第二天 00:00 重置。

  Q: 点「继续任务」后，关键词或城市被改回去了
  A: 这是有意的：续投以那条任务记录里的条件为准，
     避免你改了表单之后跑成另一个任务。
     想换条件就直接点「开始投递」，开一条新任务。

  Q: 报告里的城市和我选的不一致
  A: 2026-11-21 之前的旧版本城市代码有误，已修正。
     新版本使用 BOSS 官方城市表，全国 373 城一一对应。


【安全提示】

  · 程序只做两件事：读岗位列表、点投递按钮。
    不会碰你的账号密码，不会改你的简历，不会发聊天消息。
  · 投递记录、配置都存在本地；只有检查更新时会访问你配置的更新地址。
  · 投递间隔约 0.9 秒，避免触发风控。
    但请勿短时间连续跑多轮。
